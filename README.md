# origin-lab

本仓库打包了本地 Origin 2025 的联动 skill，用于科研绘图、改图和导出。

## 内容

- `SKILL.md`: skill 触发说明和工作流
- `scripts/`: 环境检测、Origin 出图、OPJU 改图脚本
- `references/`: Origin 自动化和绘图约定
- `agents/openai.yaml`: Codex UI 元数据

## 用法

在 Codex 中直接说：

- `用 origin-lab 帮我画这份 CSV`
- `用 origin-lab 帮我改这个 OPJU`
- `用 origin-lab 检查 Origin 自动化环境`

## 说明

仓库内容与本地可用 skill 保持一致。若更新 skill，请同步修改这里的说明并重新推送。
